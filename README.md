# Kurier — помощник курьера (PWA)

Приложение сводит воедино **посылки** (из офиц. приложения) и **письма/журналы** (которые идут мимо базы), чтобы на каждой точке ты видел весь список — и ничего не забыл. Строит оптимальный маршрут из Базы и обратно.

Всё работает **офлайн**, **бесплатно**, данные (адреса получателей) **хранятся только в телефоне** и никуда не уходят.

---

## Что умеет

- 📷 **Сканировать адреса фотографией** (OCR, распознавание текста прямо в телефоне):
  - **посылки** — снимаешь **список** с экрана офиц. приложения (можно 2–3 фото, адреса накопятся в один список);
  - **письма/журналы** — снимаешь по одному адресу.
- ✅ **Сверка после распознавания** с подсветкой: 🟢 всё найдено, 🟡 проверь, 🔴 вероятная ошибка (предложит ближайшую улицу). Правишь только жёлтое и красное.
- 🔗 **Сопоставление**: письмо/журнал автоматически «прилипает» к точке с тем же адресом, где уже есть посылка → на точке единый чек-лист (📦 посылка / 📖 журнал / ✉️ письмо).
- 📊 **Индикатор количеств** вверху экрана «Точки»: 📦 посылки · 📖✉️ журналы+письма · Σ всего.
- 🏠 **Адрес Базы задаётся в интерфейсе** (⚙️ Настройки) — старт и финиш маршрута.
- 🧭 **Оптимальный маршрут** — замкнутый цикл: **База → все точки → База**.
- 🗺️ **Навигация** — тап по точке открывает её в картах (рекомендую офлайн-карты Organic Maps).
- 🌍 **Языки интерфейса**: русский, английский, немецкий, польский.

## Установка и запуск (для разработки)

Нужен Node.js 20 (зафиксировано в `.nvmrc` и `package.json`). Зависимости ставятся **локально в проект** (папка `node_modules` — это и есть изолированное «виртуальное окружение» Node), точные версии закреплены в `package-lock.json`.

```bash
npm install        # поставить зависимости (один раз)
npm run dev        # локальный сервер разработки -> открой ссылку в браузере
npm run build      # собрать в папку dist/ (для публикации)
npm run preview    # посмотреть собранную версию
```

> ⚠️ Камера и офлайн-режим (Service Worker) работают только по **HTTPS** (или на `localhost`). Поэтому телефон тестируй через опубликованную версию, не по «голому» IP.

## Первый запуск — настройка (один раз)

Открой приложение → вкладка **⚙️ Настройки**:

1. **Язык** — выбери из четырёх.
2. **Адрес Базы** — склад, откуда стартуешь и куда возвращаешься. Введи `улица дом, индекс город` (напр. `Marktplatz 1, 17033 Neubrandenburg`) → **Сохранить**.
3. **Адресный индекс района** — загрузи файл (см. ниже). Без него приложение работает, но сверка адресов ограничена (не сможет подсвечивать 🟢/🔴 и не будет координат для маршрута).

### Как получить адресный индекс района (один раз, бесплатно)

Индекс — это список улиц/домов твоего района с координатами (публичные данные карты, **не** персональные). Делается один раз:

1. Открой https://overpass-turbo.eu, найди на карте **свой район доставки**.
2. Вставь запрос и нажми **Run**:
   ```
   [out:json][timeout:60];
   (
     node["addr:housenumber"]["addr:street"]({{bbox}});
     way["addr:housenumber"]["addr:street"]({{bbox}});
   );
   out center;
   ```
3. **Export → raw OSM data (JSON)**, сохрани как `overpass.json`.
4. Преобразуй в формат приложения:
   ```bash
   node scripts/build-index.mjs overpass.json public-index.json
   ```
5. В приложении: **Настройки → Загрузить файл индекса** → выбери `public-index.json`.

Для быстрой пробы есть готовый пример: `samples/address-index.sample.json`.

## Ежедневный рабочий цикл

1. **📷 Сканировать → тип «Посылка»** → сфоткай список из офиц. приложения (можно несколько фото). Дождись распознавания.
2. На экране **сверки** поправь 🟡/🔴 строки (🟢 пропускай) → **Добавить выбранные**.
3. **📷 Сканировать → тип «Журнал»/«Письмо»** → сфоткай адрес каждого письма/журнала по одному. Если адрес совпал с посылкой — груз добавится к той же точке.
4. **🧭 Маршрут → Построить маршрут** — получишь порядок объезда и общую длину.
5. Едешь по списку. На каждой точке видишь **чек-лист** (📦/📖/✉️) — отмечаешь отданное галочкой.
6. Тап по точке в маршруте → открывается навигация к ней.

> Совет: поставь **Organic Maps** (бесплатные офлайн-карты OSM) как навигатор по умолчанию — тогда навигация тоже работает без интернета и без передачи адресов в Google.

## Установить как приложение (офлайн)

Открой опубликованную ссылку в браузере телефона → меню → **«Добавить на главный экран»**. После этого запускается как обычное приложение и работает офлайн.

> При самом первом сканировании телефону нужен интернет один раз — чтобы скачать и закешировать модуль распознавания. Дальше OCR работает офлайн.

## Приватность (GDPR)

- Адреса получателей хранятся **только в браузере телефона** (IndexedDB). Сервера нет — данные физически некуда утекать.
- Адресный индекс — это публичные данные карт (улицы/дома), не персональные.
- Навигацию отдавай в Organic Maps (офлайн), чтобы адреса не уходили в облако.

## Структура проекта

```
src/
  core/
    normalizer.js   разбор нем. адресов -> matchKey (ядро сопоставления)
    db.js           IndexedDB: настройки, точки, адресный индекс
    geocode.js      локальный геокодинг + уверенность сверки (🟢🟡🔴)
    matching.js     привязка грузов к точкам (чек-лист)
    route.js        замкнутый маршрут: nearest-neighbor + 2-opt/Or-opt
  ocr/ocr.js        Tesseract.js: распознавание + резка списка на адреса
  i18n/             словари ru/en/de/pl + загрузчик
  ui/               экраны и навигация
scripts/build-index.mjs   сборка адресного индекса из OSM
samples/                  пример файла индекса
```
